# 首页四幕引导与创建表单执行计划

状态：用户已确认设计；尚未实现。本文由设计讨论整理，可作为新对话的执行输入。

## 1. 产品目标与范围

Cordantry 是为 MAH 引流的精致 demo。让用户理解 AI 公司如何工作、产生使用期待，并将真实规划与执行承接到 MAH。不要以完善独立公司运行平台为目标扩大范围。

本次优先实现：首页四幕模拟动画引导、同一浮层中的名称与愿景表单、跳过与回看、现有公司进入路径。MAH 真实连接作为后续独立验证阶段；不能将前端展示完成声称为 MAH 集成完成。

用户此前要求先讨论不动工；已确认本文设计，但本轮只要求生成执行文档。新对话收到明确执行请求后才开始实现。

不在首轮范围：重写后端部门模型、实现完整员工招聘/解雇、经营多个网站、SEO 自动化系统、真实收益仪表盘、制作 README 动图、购买域名、公开发布网站或发送营销消息。

## 2. 已确认的体验流程

首次打开 -> 四幕示例浮层 -> 创建我的公司/直接创建 -> 同一浮层中填写公司名称和愿景 -> 检查 MAH -> CEO 生成团队与计划 -> MAH 协调执行。

- 名称与愿景必须在同一张表单、同一步填写，不沿用现有分步输入。
- 不再单独要求用户选择 CEO Agent；CEO 是业务角色，执行工具交由 MAH 协调。
- 任一幕都可以提前直接创建；最后一幕主按钮为“创建我的公司”。
- 已有公司时进入公司；保留主动回看引导入口，不反复强制观看。
- 返回演示时保留已填写内容；示例名称、愿景不得自动污染真实表单。
- 四幕演示不执行任务、不调用模型、不消耗额度。
- 演示卡片顶部统一小字“示例演示”。

## 3. 视觉和交互

背景为现有应用尚未创建公司的初始页面，静止、模糊、压暗。前景卡片清晰；不是把卡片正文也做模糊。沿用项目现有视觉体系，不照搬 Orca 黑色主题。

桌面采用较宽的居中浮层，为演示留空间；卡片四幕之间尺寸稳定。手机保持边距，必要时浮层内部滚动；标题、按钮、动画不可溢出或重叠。

卡片顺序：当前幕标题 -> 主要模拟动画 -> 一句解释 -> 四步进度与前后切换。可直接选择其他幕。右上提供“直接创建”。最后主操作变为“创建我的公司”。

每幕约 8–12 秒，最多三个主要动作。第二幕可在该范围内适当更长。自动播放一次后停在结果画面，不自动跳到下一幕。提供暂停、重播；随时允许下一步。切幕/离开时停止旧动画，不能留后台计时器。

动画采用网页组件绘制的简化 UI 情景动画，不使用实际录屏 GIF。保留关键标题、员工职责、任务、反馈、结果；次要报告或页面内容用灰色短线表示。一次突出一个动作，避免同时出现密集文字。

关键 UI 要素可用真实品牌图标、独立员工头像和现有图标库。用户要求员工头像下方展示本次执行 Agent 的图标；不能把一个员工永久等同某个厂商工具。未分配时不虚构真实工具分配。

讲解文案跟随当前应用语言；示例英文工具保留英文。支持键盘访问、合理的对话框焦点管理、可访问按钮名称、减少动态效果偏好。减少动态效果时用静态关键状态仍能讲清故事。

## 4. 示例公司和角色

示例公司：FirstSearch Studio。

示例愿景：找到一个真实的英文搜索需求，做出第一个小工具网站，跑通验证、上线、搜索获客和持续迭代。

示例产品：独立卖家地址格式检查工具。仅检查字段缺失和格式，不声称确认地址真实存在、保证可投递。后续升级为批量检查。

这是根据用户 SEO 愿景编排的虚构案例，不是已经验证的商业机会。不要捏造真实社区引文、搜索量、KD、流量或收入。需求证据与搜索状态属于明确标注的示例。

角色保持四幕一致：

| 角色 | 职责 |
| --- | --- |
| CEO | 审查证据、确定产品方向与首版范围、调整计划 |
| 研究员 | 核对用户问题、关键词、搜索意图和竞品 |
| 开发者 | 实现核心工具、测试和上线准备 |
| 运营专员 | 页面规划、内容、收录提交、首轮分发与反馈复盘 |

MAH 接收工作、协调执行、回收结果。Codex / Claude Code / Antigravity 等是执行工具，不是员工或部门。CEO 不应与 MAH 的底层 Driver 混为同一概念。

员工添加/移除是后续产品方向，本次不插入主演示或扩展完整管理功能。

## 5. 四幕定稿

### 第一幕：说出愿景，组建你的团队

三个动作：示例公司和愿景逐渐出现 -> CEO 回应 -> 四位员工与职责展开。

CEO 回应：“先找到值得解决的问题，验证后再开发。”

研究员显示准备调研，开发者显示等待验证。强调先证据、后开发，不是所有人同时开工。

说明：“你提出目标，CEO 拟定计划和分工。团队由你调整。”

### 第二幕：通过 MAH，让团队开始工作

三个动作：研究任务经 MAH 派发执行 -> 证据返回、CEO 确认 -> MAH 协调开发与运营接手。

研究摘要依次出现，不能三段密集报告同时铺开：

- 用户问题：发货前反复检查地址，容易遗漏字段。
- 搜索意图：用户希望直接检查地址，而非只读教程。
- 首版范围：检查缺失字段与格式，不保证地址真实可投递。

CEO：“进入开发，同时准备工具页和使用教程。”

员工、MAH、执行工具关系可见，MAH 位于协调位置；员工头像下方显示示例任务对应工具图标。开发实现工具，运营同时规划页面、教程和发布材料。

说明：“员工各负其责，MAH 协调 AI 工具执行，并将成果交给下一位。”

### 第三幕：打开成果，看到网站落地

三个动作：简化浏览器与工具出现 -> 输入缺少邮编的示例地址并补充 -> 检查结果及运营交付出现。

示例工具标题：Check your shipping address。

成果为主画面，附带简短交付摘要：需求与关键词验证记录、可用检查工具、使用教程与发布材料。

运营状态区分：网站已上线 / sitemap 已提交 / Google 收录待确认。提交不等于收录或排名。

说明：“得到可用的网站，以及围绕它开展运营的第一批成果。”

### 第四幕：根据反馈，推进下一轮

三个动作：后续复盘出现反馈 -> CEO 安排验证与 MAH 派发 -> 批量检查版本出现。

时间标记：“数周后 · 示例复盘”。收录记录如出现，必须明确属于示例，不代表保证时效。无需显示搜索或收入增长曲线。

反馈：“每天处理多笔订单，逐条粘贴地址还是很慢。”

用户意见：“下一轮优先解决批量检查，先确认有多少用户需要。”

CEO 让研究员核对重复需求，再安排开发增加批量检查，运营更新教程。用多条地址的检查结果体现升级。

说明：“你决定下一步方向，团队依据反馈持续改进。”

主按钮：“创建我的公司”。

## 6. 创建表单与 MAH 边界

在同一个浮层中切换为：公司名称输入框、公司愿景多行输入框、主按钮“生成团队与计划”。不算第五幕。

目标流程：MAH 未连接时保留输入，进入安装/连接步骤；就绪后才发起真实生成。不能假装已连接、用示例数据冒充生成结果，或悄悄回退直接调用旧 Agent 路径并称其为 MAH。

首轮若尚未实现真实连接，诚实呈现待连接/暂不可用状态，完成静态演示和输入保留即可；报告剩余缺口。不要为做前端演示自动启动 MAH、导入/重建仓库或提交付费任务。

现有权限模式在新流程中的摆放尚未单独决定。先审查现有默认值与约束，保留安全语义，不因省掉一个界面而自动提高权限；遇到必要产品选择再作聚焦确认。

## 7. 已核查的 MAH 能力与限制

本机 CLI：/Applications/MAH.app/Contents/Resources/bin/mah，核查版本 0.1.1896。新会话应复查安装版本和命令帮助。

- task submit：交给调度器，支持 cwd、描述文件、JSON、元数据。没有已确认的公开 --agent 指定参数。
- task show / context / replay：任务摘要、规范文档、运行视图回放；回放不是重新执行。
- task input：运行中补充指导。
- follow-up：活跃任务接收输入；终态任务经新 intake 形成关联后续任务，不应假定沿用同一执行身份。
- project entry register / launch：支持 web、file、folder、cli 入口，可作为从 MAH 打开 Cordantry 的基础，尚未实际注册验证。
- project open：解析项目根目录，不能认为会唤起桌面对应任务。
- CLI 列出 cursor、claude、codex、antigravity、copilot 适配器；列出不代表本机已可运行。
- 内置协议有 direct/adaptive 任务拓扑，尚未验证员工间按指定职责自动交接。

只读实测遇到：project runtime list 返回 scheduler.sock 不存在；三个工具的 health 返回 Owned process tree reclamation could not be confirmed。没有启动服务或修复，也没有真实提交任务。

尚待验证：工具实际可用性、员工与任务映射、成果交付与预览、安装检测、下载后恢复上下文、打开 MAH 指定项目/任务。不得宣称这些已经完成。

## 9. 验收标准

- 四幕内容与本文一致，员工、MAH、执行工具层次清楚。
- 关键场景为组件模拟动画，不是实录 GIF；单幕停在结果，手动切幕。
- 暂停/重播/前后/直接选幕/跳过可用，切幕后无旧动画继续推进。
- 首次无公司看引导；已有公司可直接进入，能主动回看。
- 公司名称与愿景同一步输入，回看后内容保留，示例不写入真实数据。
- 无额外 CEO 工具选择；MAH 未就绪不假生成，不暗中改用直连。
- 员工头像下方有示例执行 Agent 标识，工具不是员工的永久身份。
- 不把提交 sitemap 等同收录，不保证排名、收入或短期流量。
- 移动端、桌面长文案无重叠溢出；减少动态效果下可理解；键盘焦点不穿透模态背景。
- 测试覆盖流程转换、表单保留、已有公司回归和动画控制的关键行为，避免镜像实现的无效测试。
- 启动开发服务器并提供 URL；报告运行的检查、结果和未完成项。
